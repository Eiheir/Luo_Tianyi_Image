# Luo_Tianyi_Image

> 洛佬の美图 —— 个人 GitHub 图床仓库。

本仓库以 Git 直接托管图片资源，配合 jsDelivr CDN / GitHub Raw 对外提供访问链接。
仓库内附带一个**独立**的图床管理工具（`manager/`），用于批量上传、自动分类归档、
查重、格式转换、批量取链与 Git 一键同步，方便日常维护。

## 目录结构

```
洛佬の美图/
├── LTYpicture/                 # 图库本体（原有业务，保持目录约定不动）
│   ├── emoticon/<主题>/        # 表情包（按主题分目录，3 位编号）
│   └── wallpapers&illustration/
│       ├── avatar/             # 近方形图（4 位编号）
│       ├── heng/               # 横图
│       ├── shu/                # 竖图
│       └── temporary/          # 临时中转
├── manager/                    # 图床管理工具（独立模块，可整体删除）
├── 图片命名规则.md              # 图库命名/归档约定（权威来源）
└── README.md
```

> 配置文件位于 `manager/config.json`（exe 运行时生成在 exe 旁），根目录不放配置。

## 快速开始（使用管理工具）

工具支持两种运行方式，详见 [manager/部署说明.md](manager/部署说明.md)：

- **exe 免安装（推荐）**：将 `manager/dist/LTY-图床管理器.exe` 放到仓库根目录（与 `LTYpicture` 同级）双击运行，浏览器访问 <http://127.0.0.1:3210>。
- **源码运行**：需 Node.js ≥ 18，在 `manager/` 下执行：

  ```bat
  cd manager
  npm install
  npm start
  ```

## 主要能力

- 批量上传与自动分类归档（近方形→avatar、横图→heng、竖图→shu、表情包→emoticon/<主题>/）
- 拖拽 / 点击 / **剪贴板粘贴**上传，逐文件串行提交：实时进度、失败重试、可随时停止
- 字节级 MD5 精确查重 + dHash 感知相似检测；查重面板支持「保留最高清」一键清理，保留图会自动改为同目录组内最小序号（目标被占用时保持原名）
- 上传时自动 EXIF 方向转正，可选格式转换与元数据剥离（防隐私泄露）
- 访问链接批量生成与导出：jsDelivr 主站及 Fastly / Cloudflare / Gcore 镜像、GitHub Raw；纯链接 / Markdown / HTML / BBCode；txt / json / csv / markdown 文件导出
- 图片库：目录树、大小/尺寸/格式/关键词筛选、灯箱大图预览（←/→ 浏览）、批量移动分类、目录编号规整、表情包主题改名
- 存储占用可视化统计与近 12 个月新增趋势、回收站软删除（可恢复、防覆盖、可彻底清除、过期自动清理）、Git 一键同步（先拉取远端，多机使用更稳）

## 说明

- 管理工具**只增写图库目录**，不修改、不移动、不删除图库既有文件；删除 `manager/` 即可完全移除。
- 图库归档与命名约定以 [图片命名规则.md](图片命名规则.md) 为准。
